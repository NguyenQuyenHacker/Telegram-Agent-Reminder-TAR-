## 1. Thêm tool giúp user cập nhật task ngay trong lúc nhắn tin

- Nhận diện task theo mã task hoặc theo tên
- User nhắn đã xong việc là task được ghi nhận hoàn thành
- User nhắn hủy việc là task bị bỏ
- User nhắn đổi hạn là deadline được cập nhật, lịch nhắc chạy theo hạn mới
- Task đã xong hoặc đã hủy thì không nhắc nữa
- Nhắn xác nhận lại cho user sau mỗi thay đổi

## 2. User nói hạn theo kiểu "2 ngày nữa" thì phải ra được ngày deadline

- "2 ngày nữa", "1 tuần nữa", "1 tháng nữa" phải tính ra đúng ngày deadline
- Lấy ngày user gửi tin nhắn làm mốc, theo giờ VN
- Task đang thiếu hạn, user trả lời bổ sung cũng phải ra được ngày deadline
- Nhắn lại ngày deadline vừa tính cho user xác nhận

## 3. Nhận thêm đầu vào ảnh và tin nhắn thoại

- User gửi ảnh cũng tạo được task
- User gửi tin nhắn thoại cũng tạo được task

## 4. Gộp nhiều tin nhắc thành một tin duy nhất theo mức ưu tiên

- Mỗi lượt nhắc chỉ gửi một tin, không gửi rời rạc
- Chia nhóm ưu tiên cao, bình thường, quá hạn
